# Ваш Ремонт / Vash Remont

Двуязычный адаптивный сайт ремонтной компании. Русская версия — `dist/index.html`, английская — `dist/en.html`. Переключатель RU / EN работает без JavaScript.

## Локальный запуск

```sh
npm start
```

Откройте http://localhost:4173. Установка зависимостей и сборка не нужны: HTML, CSS, JavaScript и локальная копия Three.js находятся в `dist/`.

## Публикация

GitHub Actions автоматически публикует папку `dist/` в GitHub Pages при каждом push в `main`. Workflow также можно запустить вручную во вкладке Actions. В Settings → Pages должен быть выбран источник GitHub Actions.

Все пути к ресурсам относительные, поэтому сайт работает в подкаталоге репозитория.

## Форма и изображения

Форма формирует текст заявки локально и позволяет скопировать его. Она не отправляет данные: для приёма заявок нужно подключить реальные контакты или сервер. Изображения иллюстрируют интерьерные направления и не заявлены как выполненные проекты.

Поддерживаются уменьшение анимации, просмотр изображений в диалоге и текстовый вариант при недоступном WebGL. Шрифты загружаются через Google Fonts с системными заменами; русский текст использует системный шрифт с поддержкой кириллицы. Лицензия Three.js находится в `dist/vendor/THREE-LICENSE.txt`.
